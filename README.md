# SwiftTerminal

Lightweight iOS SSH client with one-tap VPS provisioning for Claude Code.

## Requirements
- Swift 6.2
- macOS 15+ / iOS 18+
- Xcode 16+

## Tech Stack
- **SSH:** SwiftNIO SSH + Citadel
- **Terminal:** SwiftTerm
- **Key Storage:** iOS Keychain + Secure Enclave

## Build & Run
```bash
swift build
swift run
```

## Test
```bash
swift test
```
